# Architecture Decision Records (ADR)

Ten katalog zawiera Architecture Decision Records (ADR) dla projektu systemu rezerwacji wizyt.

## Format ADR

Każdy ADR zawiera:
- **Tytuł**: Krótki opis decyzji
- **Status**: Zaproponowany, Zaakceptowany, Odrzucony, Zastąpiony
- **Kontekst**: Dlaczego podejmujemy tę decyzję
- **Decyzja**: Co postanowiliśmy
- **Konsekwencje**: Pozytywne i negatywne skutki decyzji
