# Product Decision Records (PDR)

Ten katalog zawiera Product Decision Records (PDR) dla projektu systemu rezerwacji wizyt.

## Format PDR

Każdy PDR zawiera:

- **Tytuł**: Nazwa decyzji produktowej
- **Status**: Zaproponowany, Zaakceptowany, Odrzucony, Zastąpiony
- **Kontekst**: Dlaczego podejmujemy tę decyzję (problem użytkownika, potrzeba biznesowa)
- **Decyzja**: Co postanowiliśmy zaimplementować
- **Uzasadnienie**: Dlaczego taka, a nie inna funkcjonalność
- **User Stories**: Historie użytkowników
- **UX/UI Guidelines**: Wytyczne dla interfejsu
- **Metryki sukcesu**: Jak zmierzymy powodzenie
- **Konsekwencje**: Wpływ na użytkowników i biznes
